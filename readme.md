# Instagram Profile UI

A clean and responsive Instagram-inspired profile interface built using HTML and CSS.

## 📌 Project Overview

This project is a front-end practice project created to improve my HTML and CSS skills.

It recreates the main layout of a social media profile page, including a navigation bar, profile section, highlights, tabs, and post grid.

## ✨ Features

- Instagram-inspired navigation bar
- Profile picture and bio section
- Followers, following, and post statistics
- Story highlights with images
- Posts grid layout
- Hover effects on posts
- Like and comment overlay
- Profile tabs
- Responsive design for smaller screens

## 🛠️ Technologies Used

- HTML5
- CSS3
